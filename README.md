# Honorarnoten – Handy-Seite

Statische Seite (HTML, keine Daten, kein Passwort). Sie schickt Eingaben direkt an eine Google-Apps-Script-Web-App
im Google-Konto der Praxis; dort liegen alle Daten. In diesem Repository liegen **keine** Patientendaten,
**kein** Passwort und **kein** Programmcode mit Zugangsdaten.

- `index.html` – die Seite (Zeile `const API_URL = '…'` = Adresse der Web-App)
- `verbindungstest/` – Testseite für die Verbindung GitHub Pages → Google (ohne Daten)
